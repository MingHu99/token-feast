# 大肥鱼吃白饭 · TOKEN FEAST

一条胖鱼的吃饭小游戏。鼠标或手指带着它游，游到碗边就开吃，攒 token 的同时躲开鱼钩。

**纯单文件、零依赖、纯离线**：`index.html` 双击就能玩，不联网、不上传任何数据。

## 怎么玩

| | |
| --- | --- |
| 鼠标 / 手指 | 鱼跟着你游，游到碗边自动开吃 |
| W A S D / 方向键 | 键盘也能游 |
| 空格 / 点击 | 开始、重来 |
| M / 右上角喇叭 | 静音 |

- 白饭 **+120 token**，金碗 **+560**，青色小碗「灵光一闪」**+300** 并把场上所有鱼钩当场松掉
- 每吃满 15 碗开 **「大胃王时刻」**，6 秒内 token 翻倍
- 鱼钩会扣 1 颗心，3 颗心用完就翻肚皮
- 连击最多 3 倍加成；吃得越多肚子越大，也越难

## 关于数据

- 记录墙（本地前五）只存在**你自己的浏览器**里（`localStorage` 的 `tf_scores`），清掉浏览器数据即清空
- 没有后端、没有统计、没有账号、没有广告
- 音效是浏览器现场合成的，没有音频文件；手机浏览器规定「先点一下才出声」，点任意位置即可

## 手机上

屏幕宽度小于 560px 时 HUD 会自动换成小面板。手机浏览器建议横屏，或者直接玩——竖屏也能玩。

## 它从哪来

一条喜欢白饭的胖鱼，和一个闲着不用的周末下午。
「大肥鱼」这个名字在 B 站有很多二创版本，这里只是其中一条——长得像，但不是同一个。
