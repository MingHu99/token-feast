# 大肥鱼吃白饭 · TOKEN FEAST

一条胖鱼的吃饭小游戏。鼠标或手指带着它游，游到碗边就开吃，一边攒 token 一边躲开鱼钩。

单文件、零依赖、可离线：`index.html` 双击就能玩，也可以直接摆在任何静态托管上。

## 怎么玩

| | |
| --- | --- |
| 鼠标 / 手指 | 鱼跟着你游，游到碗边自动开吃 |
| W A S D / 方向键 | 键盘也能游 |
| 空格 / 点击 | 开始、重来 |
| M / 右上角喇叭 | 静音 |

## 规则

- 白饭 **+120 token**，金碗 **+560**，青色小碗「灵光一闪」**+300**
- 吃到「灵光一闪」时，场上所有鱼钩当场松掉——它是保命用的，不是加分用的
- 每吃满 15 碗进 **「大胃王时刻」**，6 秒内 token 翻倍
- 连着吃不断口能累加连击，最高 **3 倍** 加成
- 鱼钩掉下来会扣 **1 颗心**，3 颗心用完就翻肚皮
- 一局 **120 秒**；吃得越多鱼越胖，判定也越大
- 标题页按 `T` 开 **「每日挑战」**：拿当天日期当种子，同一天所有人同一副牌，比的是手不是运气
- 每局结束会把成绩记进本机的「记录墙」（前五名）

## 手机上

屏幕宽度小于 560px 时 HUD 会自动换成小面板；竖屏也能玩，横屏更宽敞。手机浏览器规定先有一次点击才能出声，点任意位置即可。
